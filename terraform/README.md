# =============================================================
# Terraform - Infraestructura como Código (IaC)
# =============================================================
#
# Este directorio define la infraestructura de la API de Pólizas
# en AWS usando ECS Fargate + ECR + VPC + CloudWatch Logs.
#
# Requisitos:
#   - Terraform >= 1.5 instalado
#   - Credenciales AWS configuradas (aws configure o variables de entorno)
#
# Uso básico:
#   terraform init      # Inicializa el backend y descarga providers
#   terraform plan      # Previsualiza los cambios
#   terraform apply     # Aplica la infraestructura
#   terraform destroy   # Elimina la infraestructura
# =============================================================
